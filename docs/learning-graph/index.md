# Learning Graph

A **learning graph** is a map of every concept in this book and which concepts you need to know first. *Gut Check* has **337 concepts** connected by **538 prerequisite links**, grouped into 13 categories, from Foundations to Living With Illness.

[Open the interactive Learning Graph Viewer](../sims/graph-viewer/main.html){ .md-button .md-button--primary }

## How it was built

1. Each chapter was assigned 14 to 22 concepts in a fixed concept list.
2. Each concept lists the concepts it depends on. A concept can only depend on concepts from the same chapter or an earlier one, so the book never uses an idea before teaching it.
3. A script checks that the graph has no loops, no missing links, and no concept left unconnected.
