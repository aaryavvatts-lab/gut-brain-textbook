# How to Cite

If this book helped your work, please cite it.

**APA (7th edition)**

Sharma, A. (2026). *Gut check: The neuroscience of how your gut and brain talk* (Version 1.0). https://aaryavvatts-lab.github.io/gut-brain-textbook/

**MLA (9th edition)**

Sharma, Aaryav. *Gut Check: The Neuroscience of How Your Gut and Brain Talk*. Version 1.0, 2026, aaryavvatts-lab.github.io/gut-brain-textbook/.

**BibTeX**

```bibtex
@book{sharma2026gutcheck,
  author    = {Sharma, Aaryav},
  title     = {Gut Check: The Neuroscience of How Your Gut and Brain Talk},
  year      = {2026},
  version   = {1.0},
  publisher = {GitHub Pages},
  url       = {https://aaryavvatts-lab.github.io/gut-brain-textbook/},
  note      = {Free interactive textbook, CC BY-NC-SA 4.0}
}
```

To cite one chapter, add the chapter title and its web address. The repository also includes a `CITATION.cff` file, so GitHub shows a "Cite this repository" button.
