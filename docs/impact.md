# Impact and Reviews

A free book only matters if it helps someone. This page keeps an honest, public record of who has checked the book, where it has been used, and what readers learned. Every entry is real and dated. Nothing is listed until it actually happens.

!!! mascot-thinking "Why track this?"
    ![Vee thinking](img/mascot/thinking.png){ class="mascot-admonition-img" }
    The same rule the Hype Meter uses for science applies to this book: a claim needs evidence. "This book helps people" is a claim, so this page collects the evidence.
