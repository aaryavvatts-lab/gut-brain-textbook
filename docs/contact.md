# Contact

The best way to reach me is through GitHub. You don't need to know how to code; the forms walk you through it.

| I want to... | Use this |
|---|---|
| **Report an error** (a fact, a broken link, a sim that doesn't work) | [Error report form](https://github.com/aaryavvatts-lab/gut-brain-textbook/issues/new?template=1-error-report.yml) |
| **Tell you I'm using the book** in a class, club, or support group | [Classroom use form](https://github.com/aaryavvatts-lab/gut-brain-textbook/issues/new?template=2-classroom-use.yml) |
| **Suggest an improvement** | [Suggestion form](https://github.com/aaryavvatts-lab/gut-brain-textbook/issues/new?template=3-suggestion.yml) |
| **Offer an expert review** (clinicians, researchers, patient advocates) | [Expert review form](https://github.com/aaryavvatts-lab/gut-brain-textbook/issues/new?template=4-expert-review.yml) |

Every confirmed correction is listed on the [Accuracy and Corrections](accuracy.md) page.

!!! note "Please don't send personal health information"
    GitHub issues are public. Don't include your own medical details. This book can't give personal medical advice; please talk to your doctor.
