# Sources Policy: Gut Check

## Start here: the verified dossiers
Every chapter writer starts from these files, which list sources someone opened, the exact claims they support, evidence grades, and traps:
- `sources/verified-ch01-05.md`
- `sources/verified-ch06-10.md`
- `sources/verified-ch11-15.md`
- `sources/verified-ch16-20.md`
- `sources/verified-lead-addendum.md` (gaps the lead editor closed)

Writers may add more sources, but only ones they open themselves.

## Never use
Content farms, AI-generated sites, supplement company blogs (except as examples of marketing, labeled as such), sources without authors or dates, social media posts as evidence, and any page you did not open. Never cite the NIH Human Microbiome Project page for the "10 to 1" ratio (it's outdated), and never cite Vighi 2008 as support for "70% of the immune system is in the gut."
